# Walkthrough: Social Marketplace & Peer Negotiation

The D-MEX Protocol frontend now features an integrated **Social Marketplace** built directly into the web dashboard. This feature transitions the application from a simple order book into a full-fledged **Peer Discovery Hub** where users can scout for specific GameAssets, verify on-chain reputation, and negotiate trades in real-time.

---

## 1. Peer Discovery Architecture
We introduced a brand new `Peer Discovery` tab inside the main Barter Container. 

When you navigate to this tab, the application loads a dynamic layout composed of two primary sections:
1. **The Discovery Grid**: A responsive flex-grid featuring **Trader Cards**. Each card acts as an aggressively transparent look at a network participant. Instead of just showing random wallet addresses, it prominently features their **Trust Reputation %** and a categorized list of the assets they currently hold (e.g., *DGLD*, *Sword*, *Commodity*).
2. **Friends & History Sidebar**: As requested, we built a dedicated tracking UI labeled `Recent Associates` anchored to the right side of the screen.

## 2. Real-Time Chat & Negotiation
To bridge the gap between discovery and execution, we implemented a full WebSocket-driven chat module.

- **Negotiation Widget**: When you click the `Negotiate` button on any Trader Card, a sleek, glassmorphic chat widget slides up from the bottom right corner of the screen. 
- **WebSocket Backend Relay**: The Node.js `guardian.js` server was updated. The Arbiter Guardian now listens for incoming generic JSON payloads of `type: 'chat'`. When it receives one, it instantly broadcasts the message across the WebSocket mesh to connected clients.
- **Local Message UI**: The frontend intelligently intercepts these chat payloads, color coding sent messages (Neon Green) and received messages (Dark Glass), making back-and-forth negotiation seamless and instantaneous.

> [!TIP]
> **To Test the Logic:** Because this is a static demonstration prototype connected to the Sepolia testnet, I have pre-injected four high-profile "Mock Traders" into the grid. You can click "Negotiate" on any of them to test the chat UI, which will broadcast your typed messages to the local Guardian server!

## 3. Persistent Associate Tracking
The `Recent Associates` (Friends List) panel actively updates itself based on your behavior.

When you initiate a negotiation with a peer by clicking their card, the frontend logic pushes their address into a local session `friendsList` array. The sidebar instantly re-renders, adding them to your associative network with a count of your past simulated interactions, allowing you to quickly jump back into a chat with trusted counterparties!
