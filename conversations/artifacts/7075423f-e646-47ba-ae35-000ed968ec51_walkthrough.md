# Sprint 5 Walkthrough — Interactive Marketplace Swap System

## Overview

Built a complete peer-to-peer negotiated swap flow for the D-MEX protocol: **discover assets → inspect holders → negotiate via chat → agree on terms → paste addresses → verify → execute swap**.

---

## Changes Made

### 1. Asset Marketplace (Open Market Tab)

The "Open Market" tab was transformed from a simple order list into a full **Asset Marketplace** with:

- **Search bar** — filter by asset name, address, or description
- **Type filter pills** — All / ERC-20 / ERC-721 / ERC-1155
- **Listing cards** with asset icon, name, market value, holder gradient avatar, reputation score, swap count, listing age
- **"Negotiate" button** — opens chat with that holder
- **"Start Swap" button** — switches to Propose Intent tab with counterparty address pre-filled

### 2. Enhanced Negotiation Chat with Calculator

The chat widget was upgraded with:

- **Gradient avatar** in chat header (derived from address hex hash)
- **Reputation badge** showing live rep% and swap count
- **Action bar** with three utility buttons:
  - 🖩 **Calculator** — toggle in-chat calculator for pricing operations
  - ↕ **Propose** — sends a structured swap proposal message and pre-fills the swap UI
  - 📋 **My Addr** — copies your address to clipboard and sends it in chat
- **Full calculator** with ÷, ×, −, + operations, `=` to evaluate, `C` to clear, and `📤 Send` to post the result as a chat message

![Chat widget with negotiate and action bar visible](C:/Users/USER/.gemini/antigravity/brain/7075423f-e646-47ba-ae35-000ed968ec51/chat_negotiate.png)

### 3. Counterparty Address Bar

Added to the top of the "Propose Intent" tab:

- **Paste-able address input** with monospace font and clipboard paste button
- **Auto-resolving profile preview** — when a valid 0x address is pasted:
  - Gradient avatar (color derived from address hex)
  - Short address display
  - Reputation badge (green/yellow/red based on score)
  - Swap count
- Address is used as the `counterparty` parameter in `proposeTrade()`

![Counterparty address bar with paste input](C:/Users/USER/.gemini/antigravity/brain/7075423f-e646-47ba-ae35-000ed968ec51/counterparty_bar.png)

### 4. ATM-Style Swap Verification Modal

Before any on-chain transaction fires, users now see a **full verification modal** (bank transfer style):

- **Shield icon** and "Verify Your Swap" header
- **Two-column layout**: "You Send" (left) ↔ "They Receive" (right)
- Each side shows: gradient avatar, short address, asset icon, asset name + amount, estimated USD value
- **Protocol terms reminder** in yellow warning bar
- **"Cancel"** and **"✓ Confirm & Execute Swap"** buttons
- Only after explicit confirmation does the blockchain transaction proceed

---

### 5. Guardian API — Marketplace Endpoint

Added to [guardian.js](file:///c:/Users/USER/OneDrive/Documents/Desktop/FYP/D_MEX%20PROTOCOL/guardian/guardian.js):

- `GET /api/marketplace` — returns all open listings with holder reputation data
- `POST /api/marketplace` — users can submit their own listings
- In-memory listings store with 5 seed entries
- Each listing includes: seller address, asset info, asking price, market value, description, timestamp
- Listings are enriched with `holderProfile` data (reputation, total swaps)

---

### 6. Gradient Avatar System

A new utility generates unique, deterministic avatars from Ethereum addresses:

- **Color**: Two-tone gradient derived from address hex bytes (`hsl(h1) → hsl(h2)`)
- **Initials**: First two hex characters of the address (e.g., `1A`, `9F`)
- Used consistently across: marketplace listings, chat headers, friends list, counterparty preview, and verification modal
