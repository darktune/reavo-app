# REAVO SEO DOMINANCE AUDIT

## EXECUTIVE SUMMARY
REAVO is built as a Client-Side Rendered (CSR) Single Page Application (SPA) using React (Vite) and hosted on Vercel. While the application is fast and visually premium, its current SEO architecture is **fragile**. Because content is rendered entirely in JavaScript, non-JS bots (like social media link previewers and some search engines) will see a blank page. Googlebot can execute JS, but relying solely on CSR without a foundational SEO architecture limits REAVO's ability to dominate search results for highly competitive queries like "REAVO campus gadgets" or specific product searches in Nigeria.

Currently, REAVO is missing critical technical foundations: no sitemap, no robots.txt, no dynamic metadata, and no structured data (schema.org). 

The good news: `react-helmet-async` is already installed, meaning we can rapidly deploy a dynamic metadata system to fix the most pressing issues.

## TECHNICAL OBSERVATIONS

### INDEXATION & CRAWLABILITY
- **Framework:** React SPA (Vite).
- **Output:** The production build (`dist/index.html`) contains only `<div id="root"></div>`.
- **Problem:** There is no server-side HTML generation (SSR/SSG). Google must spend rendering budget to see your content.
- **Missing Files:** 
  - `public/robots.txt` is missing.
  - `public/sitemap.xml` is missing.
- **Admin Security:** `/admin` routes do not have a `<meta name="robots" content="noindex">` tag. While protected by auth, crawlers hitting these URLs will see the login redirect rather than a hard `noindex`.

### METADATA & HEADINGS
- **Titles:** Static `<title>reavo-app</title>` across the entire site.
- **Descriptions:** Missing entirely.
- **Open Graph (Social):** Missing entirely.
- **Headings:** The site uses headings primarily for styling rather than structural hierarchy (e.g., missing strong `<h1>` tags on key pages).

### ECOMMERCE & STRUCTURED DATA
- **Product Pages:** No unique titles or descriptions per product.
- **Schema Markup:** No `Product`, `Offer`, or `Organization` JSON-LD structured data. This means Google cannot display rich snippets (prices, availability, ratings) in search results.
- **Database Integration:** Product data lives in Supabase, but the SEO tags are not currently wired to fetch and inject this data into the `<head>`.

### INTERNAL LINKS
- Links are handled via React Router (`<Link>`), which is good for internal routing, but the lack of a semantic breadcrumb structure limits crawler understanding.

## PRIORITIZED FIXES

### P0 — CRITICAL (Do Now)
**1. Implement Dynamic Routing Metadata**
- **Problem:** Every page says "reavo-app".
- **Fix:** Utilize the installed `react-helmet-async` to inject unique `<title>` and `<meta name="description">` tags on every route.
- **Target:** `[Product Name] | REAVO` for products, `REAVO — Campus Gadgets in Nigeria` for home.

**2. Create `robots.txt` and `sitemap.xml`**
- **Problem:** Crawlers have no map.
- **Fix:** Generate a static `sitemap.xml` mapping the core pages (`/`, `/shop`, `/about`, `/story`, `/partnerships`). Create a `robots.txt` that allows all but blocks `/admin` and `/checkout`.

### P1 — HIGH (Do Before Public Launch)
**1. Implement E-commerce Structured Data (JSON-LD)**
- **Problem:** Google doesn't know you sell products.
- **Fix:** On the `ProductPage.jsx`, dynamically generate `Product` schema using the Supabase data (Name, Price in NGN, Image URL, Stock Status).

**2. Implement Organization Structured Data**
- **Problem:** Google doesn't know REAVO is a legitimate Nigerian business.
- **Fix:** Add `Organization` schema to the homepage defining the brand, logo, and contact info.

**3. Admin & Checkout No-Index**
- **Problem:** We don't want Google indexing secure or utility pages.
- **Fix:** Add a `<meta name="robots" content="noindex, nofollow">` via Helmet to all `/admin/*` and `/checkout` routes.

### P2 — MEDIUM (Do Later)
**1. Semantic HTML Refactor**
- Replace generic `<div>` wrappers with `<main>`, `<article>`, `<section>`, and `<nav>`. Ensure every page has exactly one `<h1>`.

**2. Open Graph & Social Cards**
- Inject `og:image`, `og:title`, and `twitter:card` meta tags globally, and dynamically for product pages so links shared on WhatsApp/Twitter look premium.

**3. Alt Text Audit**
- Ensure all product images pulled from Supabase have descriptive `alt` attributes (`alt={product.name}`).
