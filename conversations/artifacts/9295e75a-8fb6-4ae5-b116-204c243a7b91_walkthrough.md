## Part 2: Global iOS Glass Design (Wizard & Dashboard)

We have reverted the UI back to its core 4-step Wizard structure for a guided user experience, but applied a **global iOS minimalist glassmorphism aesthetic** across every interactive component.

### Aesthetic Upgrades:
1. **Global Glassmorphism:** Every card, container, input field, and button now features a frosted glass look (`backdrop-filter`, subtle borders, and `inset` shadows).
2. **Interactive Hover Lift:** All components dynamically interact with the cursor. Hovering over the `wizard-card`, `simulate-panel`, or buttons causes the glass to brighten, elevate, and cast a deeper shadow, creating a premium fluid feel.
3. **Consistent Theme:** Both the main dApp and the Guardian Dashboard follow the exact same visual language.
