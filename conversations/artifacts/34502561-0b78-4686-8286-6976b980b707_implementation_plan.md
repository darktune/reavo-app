# DMEX UI + Guardian AI — Full Build Plan

## Background

The `UniversalVault` contract is **live on Scroll Sepolia** at proxy address `0x409181aa3805291d04E4C1C8be7FF9d052ea2814`. The Guardian AI backend (`guardian/`) is already scaffolded with a REST `/sign` endpoint and a Chart.js dashboard. 

This plan builds three things:

1. **Frontend dApp** — a MetaMask-style 4-step barter wizard (pure HTML/JS/CSS, no framework needed, opens directly from `frontend/index.html`)
2. **Guardian AI upgrade** — WebSocket live push + a "Simulate Swap" panel in the dashboard
3. **Integration glue** — the frontend calls the Guardian before calling the contract

## Proposed Changes

### Component 1 — Frontend dApp (`frontend/`)

#### [NEW] [index.html](file:///c:/Users/USER/OneDrive/Documents/Desktop/FYP/solidity/frontend/index.html)
Single-page barter dApp. 4 wizard steps rendered with `display:none` switching:

| Step | Name | What it does |
|------|------|-------------|
| 1 | **Connect** | MetaMask detect + Scroll Sepolia auto-switch via `wallet_switchEthereumChain` |
| 2 | **Build Offer** | Choose asset type, paste token address, enter amount/tokenId; pick counterparty address; set expiry (slider); paste secret; click "Get AI Approval" → calls Guardian, shows animated risk badge |
| 3 | **Review & Commit** | Side-by-side bundle view, USD estimates, AI badge result, one "Commit Swap" button that calls `commitSwap()` on-chain |
| 4 | **Counterparty Accept** | Lookup existing swapId, enter secret, calls `executeSwap()` — shows transaction progress bar (Pending → Broadcasting → Confirmed) + Scrollscan link |

Visual design: dark glassmorphism (`#0d0f1a` background matching dashboard), Inter font, animated step progress bar at the top, same colour system as the guardian dashboard (green/orange/red).

#### [NEW] [app.js](file:///c:/Users/USER/OneDrive/Documents/Desktop/FYP/solidity/frontend/app.js)
- **MetaMask connection** — `eth_requestAccounts`, auto-switch to chainId `0x8274f` (Scroll Sepolia = 534351)
- **swapId generation** — `ethers.id(secret + counterparty + Date.now())` 
- **secretHash** — `ethers.sha256(ethers.toUtf8Bytes(secret))` — this matches `sha256(abi.encodePacked(secret))` in Solidity
- **Guardian call** — `POST http://localhost:3000/sign` with bundle data, render badge inline
- **`commitSwap()`** — calls contract via `ethers.Contract` using ABI fragment; shows spinner
- **`executeSwap()`** — calls `/sign` to get AI signature, then calls contract; shows progress bar
- **Event listener** — subscribes to `SwapCommitted` / `SwapExecuted` / `SwapRefunded` events to auto-update UI

#### [NEW] [styles.css](file:///c:/Users/USER/OneDrive/Documents/Desktop/FYP/solidity/frontend/styles.css)
- Glassmorphism wizard card with `backdrop-filter: blur`
- Animated step progress bar (4 nodes, filled with gradient as steps advance)
- Asset pill tags (colour-coded: ERC20 purple, ERC721 blue, ERC1155 orange)
- AI risk badge animation (pulse → result with colour)
- Transaction progress bar (3 stages with shimmer animation)
- Mobile-responsive grid for the bundle comparison view
